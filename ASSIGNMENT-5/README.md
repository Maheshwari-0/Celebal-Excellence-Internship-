# Week 5 - Apache Spark Data Cleaning Assignment

## Overview

This repository contains my Week 5 Apache Spark assignment. The objective of this assignment is to practice common data cleaning and data transformation techniques using PySpark in Databricks.

The assignment covers different DataFrame operations such as handling duplicate records, dealing with missing values, filtering data, performing aggregations, converting data types, and grouping records for analysis.

## Files

* **Spark DataFrame Operations.ipynb** – Databricks notebook containing all solutions.
* **sales_records.csv** – Dataset used to perform the assignment.
* **README.md** – Project documentation.

## Topics Covered

* Removing duplicate records
* Handling null values
* Filtering DataFrames
* GroupBy and aggregation
* Working with timestamps
* Data type conversion
* Shuffle and wide transformations
* Data cleaning using PySpark
* Aggregation functions (`sum`, `avg`, `min`, `max`, `mean`)

## Tools Used

* Apache Spark (PySpark)
* Databricks Community Edition
* Python
* GitHub

## What I Learned

While working on this assignment, I gained hands-on experience with Spark DataFrames and learned how different transformations work. I also understood why handling null values, removing duplicates, and using the correct data types are important before performing analysis. This assignment also helped me understand concepts like shuffle operations and wide transformations.

## How to Run

1. Upload the dataset to Databricks.
2. Import the notebook.
3. Attach a Spark cluster.
4. Run the notebook cells in sequence.
